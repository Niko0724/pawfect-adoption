// =============================
// PAWFECT ADOPTION - CURRENT NOTES
// =============================

// Project overview:
// - React + Vite SPA for pet adoption.
// - Uses localStorage for auth, users, favorites, and adoption requests.
// - Includes dark-mode toggle, search + tag suggestions, favorites, requests, help, and settings.

// App structure:
// - src/App.jsx: main router + global drawer state + dark mode state.
// - src/main.jsx: root render with BrowserRouter and App.css import.
// - src/App.css: layout, components, theme variables, dark-mode overrides.

// Components:
// - Header.jsx
//   * sticky header that hides on scroll down and reappears on scroll up or mouse near top.
//   * search bar with tag suggestions and Enter commit.
//   * opens UserDrawer via nav button.
// - PetCard.jsx
//   * pet tile with image, favorite toggle, species/breed display, dynamic tag pills.
//   * includes Adopt / View Profile actions.
// - AdoptionModal.jsx
//   * adoption request form modal with detail inputs and submit callback.
// - FilterBar.jsx
//   * filter buttons for pet species and tag-based filtered view.
// - Hero.jsx
//   * landing hero panel with featured message.
// - ScrollToTopButton.jsx
//   * global floating button to scroll the page upward.
// - UserDrawer.jsx
//   * slide-out drawer with links for Favorites, Requests, Settings, Help, Home, and Logout.

// Pages:
// - Home.jsx
//   * search + filter works across name, breed, species, and tags.
//   * displays pet cards and opens the adoption modal.
//   * logout is handled via auth utility.
// - Favorites.jsx
//   * shows favorited pets from current user.
//   * includes local search and empty state when no favorites exist.
// - Requests.jsx
//   * shows adoption requests from local DB.
//   * enriches each request with pet and shelter details.
//   * search filter works on pet name, breed, species, shelter name, and status.
// - Help.jsx
//   * help center with FAQs, contact support, report issue, and chat message forms.
// - Settings.jsx
//   * dark mode toggle and password change form.
//   * updates localStorage user record and current user session.
// - PetProfile.jsx
//   * pet detail page with image, location, story, traits, and adopt button.
//   * includes back navigation.
// - ShelterProfile.jsx
//   * shelter detail page with contact info, email, phone, and address.

// Data and utilities:
// - src/data/animals.js: pet dataset with tags, species, breed, location, image, etc.
// - src/data/shelters.js: shelter dataset used for profiles and request linking.
// - src/utils/auth.js: auth helpers for register, login, logout, updateUser, toggleFavorite.
// - src/utils/adoption.js: request helpers for createAdoptionRequest, updateRequestStatus, getAllRequests.
// - src/utils/database.js: local DB read/write helpers for storing adoption request data.

// Current behavior notes:
// - Dark mode is stored in localStorage key `pawfect_theme` and toggles `body.dark`.
// - Favorites persist across reloads and update both the users list and current session.
// - Search suggestions are derived from unique pet tags and commit on Enter or suggestion click.
// - Header uses a lightweight auto-hide/show UX to preserve screen space.
// - The drawer is used as the main app navigation for support pages and account actions.

// Work in progress / review:
// - `src/App.css` dark mode styling has broad coverage, but there may still be panels or inputs needing fine-tuning.
// - `src/pages/Requests.jsx` depends on `getAllRequests()` from `src/utils/adoption.js`.
// - `src/pages/Favorites.jsx` currently disables the adopt modal on fav cards by passing a no-op onAdopt.
